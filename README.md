# CommonMarket Analytics

> **Это учебный репозиторий** модуля «Git» курса CommonData. Команда, задачи и история изменений вымышленные, но устроены так же, как в настоящей команде аналитики.
>
> **Не клонируй его напрямую.** Сначала нажми **Fork** вверху страницы, сними галочку **Copy the `main` branch only** и работай в своей копии. Пошагово — в теме «2. Форк и клонирование» модуля «Git».

Репозиторий команды аналитики маркетплейса **CommonMarket**. Здесь живёт всё, что команда считает и автоматизирует: SQL-витрины для дашбордов, словарь метрик, Python-скрипты отчётов и DAG-и для Airflow.

## Структура

```
.
├── sql/
│   ├── marts/      — витрины: их каждый день пересчитывает Airflow
│   └── adhoc/      — разовые запросы под вопросы продакта
├── scripts/        — Python: функции метрик и еженедельный отчёт
├── dags/           — DAG-и Airflow, которые наполняют витрины
├── data/           — небольшие выгрузки для локальных проверок
└── docs/           — словарь метрик
```

## Витрины

| Витрина | Что считает | Источник | Обновление |
|---|---|---|---|
| `dm_sales_daily` | заказы, покупатели, GMV и средний чек по дням | `orders` | ежедневно |
| `dm_active_users_daily` | DAU по устройствам | `sessions` | ежедневно |
| `dm_funnel_daily` | воронка: просмотр → корзина → оформление → покупка | `events` | ежедневно |
| `dm_retention_cohorts` | retention месячных когорт по успешным заказам | `users`, `orders` | еженедельно |

Все метрики считаются по определениям из [docs/metrics.md](docs/metrics.md).

## Как запустить отчёт локально

Нужен Python 3.10 или новее, сторонние библиотеки не нужны. Из корня репозитория:

```bash
python scripts/weekly_report.py
```

Скрипт читает `data/orders_sample.csv` и сохраняет отчёт в `reports/weekly_report.md`. Папка `reports/` указана в `.gitignore`, поэтому отчёты в репозиторий не попадают.
